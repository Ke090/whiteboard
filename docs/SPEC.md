# ホワイトボード仕様

## 目的

Android スマートフォンの Chrome で、指を使ってすぐに気持ちよく書けるシンプルなホワイトボードを提供する。GitHub Pages から静的ファイルとして配信し、サーバーやアカウントを必要としない。

## 機能仕様（初版）

- 1 本指またはペンによる自由描画
- ペンと消しゴムの切り替え
- 描画単位の Undo / Redo
- ペン色の変更
- 線の太さの変更
- 確認操作付きの全消去
- 描画の端末内への自動保存と再読み込み時の復元
- 画面サイズ・向きの変更に追従する描画領域

## 操作方法

1. 白い描画領域を 1 本指でなぞって描く。
2. 上部ツールバーの「ペン」「消しゴム」で道具を切り替える。
3. 色ボタンと太さスライダーでペンを調整する。
4. 「戻す」「進む」で直前の操作を取り消し、またはやり直す。
5. 「全消去」で確認後にすべての線を消す。全消去も「戻す」で復元できる。

描画領域ではブラウザのスクロールやピンチズームを抑止する。ツールバーは通常どおりタップして操作する。

## データ保存方法

描画線を正規化した座標、色、太さ、道具の種類からなる JSON として、操作完了のたびにブラウザの `localStorage` へ保存する。データは利用中の端末・ブラウザ内だけに置かれ、外部へ送信しない。保存領域が使えない場合も描画自体は継続できる。

## 今後追加する可能性のある機能

- PNG 画像としての書き出し・共有
- 複数ボードの管理
- 背景色や方眼の選択
- オフライン利用を補助する PWA 対応
- スタイラスの筆圧対応

ログイン、クラウド同期、OCR は初版の対象外とする。
